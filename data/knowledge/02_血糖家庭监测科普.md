# 家庭血糖监测科普（演示知识库）

> 免责声明：科普演示材料，**非**诊疗方案。糖尿病管理须遵专科医生意见。

## 家庭血糖监测的意义

- 了解空腹、餐后与用药/运动后的血糖波动。
- 帮助发现低血糖风险与高血糖趋势。
- 血糖仪是常见家用医疗器械，客服常被问「这个数正常吗」。

## 常见参考范围（示意，成人非孕）

| 场景 | 参考范围（mmol/L，示意） |
| --- | --- |
| 空腹 | 约 3.9–6.1 |
| 餐后 2 小时 | 一般希望 <7.8（人群与诊断标准因指南而异） |
| 低血糖警惕 | 通常 <3.9，出现出汗、心慌、意识模糊需立即处理并就医指导 |

本 Demo 工具 `classify_blood_glucose`：
- `fasting=true`：<3.9 偏低；3.9–6.1 大致正常；>6.1 偏高（示意）
- `fasting=false`（餐后示意）：<3.9 偏低；3.9–7.8 大致可接受；>7.8 偏高

## 采血与仪器使用要点

1. 按说明书安装试纸，注意有效期与保存条件。
2. 采血前清洁干燥手指，避免酒精未干导致读数偏差。
3. 记录测量场景（空腹/餐后/运动后）与症状。
4. 读数异常先复测一次，并结合症状决定是否就医。

## Agent 可回答的典型问题

- 「空腹 6.5 算高吗？」→ 调用分类工具 + 检索本文。
- 「餐后两小时怎么测？」→ 检索测量要点。
- 「低血糖怎么办？」→ 强调就医与安全，不做处方。

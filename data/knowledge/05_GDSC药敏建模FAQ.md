# GDSC 药敏建模 FAQ（课题数据场景 · 演示）

> 基于作者在 GDSC / Cell Model Passports 表达 → 药物 AUC 任务上的实验叙述，供 RAG 演示。

## 数据是什么

- **GDSC**：常见药物基因组学资源，可用药物响应（如 AUC）作为连续标签。  
- 表达来源可升级为 Cell Model Passports 的 RNA-seq（TPM → log2(TPM+1)），再与药物表按细胞系 ID 对齐。  
- 示例任务：5-Fluorouracil（5-FU）等药物的表达 → AUC 预测。

## 规模量级（课题记录）

- 全量表达面板与 5-FU 重叠后，样本量约 **n≈397**；原始基因维可达数万，常 train-only 预筛至 top-50。  
- 多 seed 下 H2 的 Test R² 约 **0.27±0.15** 量级，与 RF/XGB 接近；药敏任务噪声大，不宜与 UCI 玩具集混平均吹嘘。

## 可解释边举例

在部分划分上可导出与 5-FU 代谢叙事相关的 hub 交互（如涉及 TYMP 的边）。主张应强调「置换敏感性 / 可解释」，避免夸大全面板全面超越 PLSR。

## Agent 可回答的问题示例

- 「你们药敏实验大概多少样本？」→ 检索本文 n≈397。  
- 「Residual-DPLS 和 PLSR 比怎么样？」→ 结合公开基准与 GDSC 分开说。  
- 「为什么要做硬边？」→ 回到方法摘要：交互可解释 + 软融合稳健。
